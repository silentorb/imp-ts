# imp-collection-transforms

Declarative **`NodeLibrary`** of collection combinators (`filter`, `sort`, `limit`, …) and predicate/scalar helpers for Imp graphs.

Depends only on `imp-spec`. Load via `imp-registry`; lower to SQL with `imp-sql`.

```ts
import { collectionTransformsLibrary } from "imp-collection-transforms"
```

See [`docs/features/collection-transforms.md`](../../docs/features/collection-transforms.md).
