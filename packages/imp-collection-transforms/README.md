# imp-collection-transforms

Declarative **`NodeLibrary`** of collection combinators (`filter`, `sort`, `limit`, …) and predicate/scalar helpers for Imp graphs.

Depends only on `imp-core-types`. Load via `imp-registry`; lower to SQL with `imp-sql`.

```ts
import { collectionTransformsLibrary } from "imp-collection-transforms"
```

See [`imp-spec` collection-transforms](https://github.com/silentorb/imp-spec/blob/main/docs/packages/imp-collection-transforms/collection-transforms.md).
