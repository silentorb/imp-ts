# imp-pathing

Declarative **`NodeLibrary`** of GQL-like path operators (`traverse`, …) for Imp graphs over a host-supplied node collection and edges relation.

Depends only on `imp-spec`. Load via `imp-registry`; lower to SQL with `imp-sql`.

```ts
import { pathingLibrary } from "imp-pathing"
```

See [`docs/features/pathing.md`](../../docs/features/pathing.md).
